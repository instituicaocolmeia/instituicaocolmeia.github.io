# Política de Privacidade – Como melhorar o mundo Última atualização: 09/05/2026

A presente Política de Privacidade descreve como o aplicativo Como melhorar o mundo (“App”), desenvolvido por Instituto Colmeia (“nós”), trata os dados dos usuários.

Ao utilizar o App, você concorda com esta Política.

Dados que coletamos Atualmente, o App não coleta, armazena ou compartilha dados pessoais dos usuários.

Finalidade do uso dos dados Como não há coleta de dados pessoais nesta versão, não há tratamento de dados para fins de perfilamento, marketing ou compartilhamento com terceiros.

Anúncios e serviços de terceiros Atualmente, o App não exibe anúncios e não utiliza serviços de terceiros para análise de uso.

Compartilhamento de dados Nós não vendemos dados pessoais e, nesta versão, não realizamos compartilhamento de dados pessoais com terceiros.

Armazenamento e retenção Como não há coleta de dados pessoais nesta versão, não há retenção de dados pessoais de usuários.

Segurança Adotamos medidas técnicas e organizacionais razoáveis para manter a segurança do App.

Direitos do usuário (LGPD e legislações aplicáveis) Nos termos da legislação aplicável, você pode solicitar informações sobre eventual tratamento de dados pessoais, quando aplicável.

Privacidade de crianças O App é destinado ao público geral. Caso seja identificado tratamento indevido de dados de menores, tomaremos as medidas cabíveis para remoção.

Transferência internacional de dados Nesta versão, não há transferência internacional de dados pessoais, pois não há coleta de dados pessoais.

Alterações desta Política Podemos atualizar esta Política periodicamente. A versão mais recente estará sempre disponível na URL informada na loja do aplicativo.
